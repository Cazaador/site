# BROKERPRO COMMUNITY — Копия сайта

## Структура проекта

```
brokerpro-community/
├── index.html              # Главная страница
├── css/
│   └── style.css           # Все стили
├── js/
│   └── main.js             # Весь JavaScript
├── img/                    # Папка для изображений
│   ├── phone.png           # Телефон в lead-banner (скачайте с оригинала)
│   ├── conference.jpg      # Фото конференции
│   └── ...                 # Прочие изображения
├── files/
│   └── videos/             # Папка для видео
│       ├── 1.mp4
│       ├── 2.mp4
│       └── 3.mp4
└── README.md
```

## Как добавить изображения и видео

Загрузите оригинальные файлы с сайта https://community.brokerpro.estate/ в соответствующие папки:

### Изображения (папка /img/):
- `phone.png` — с https://community.brokerpro.estate/img/lead-banner/phone-desktop.png
- `conference.jpg` — с https://community.brokerpro.estate/img/problems.png
- Все остальные изображения доступны по пути `/img/` на оригинальном сайте

### Видео (папка /files/videos/):
- `1.mp4`, `2.mp4`, `3.mp4` — видеоматериалы с мероприятий

## Реализованный функционал

✅ Закреплённая шапка (sticky navbar) с возвратом наверх по клику на логотип  
✅ Бургер-меню с навигацией по блокам  
✅ Интерактивная схема "BROKERPRO COM" с попапами при клике  
✅ Плавное появление блоков при скролле  
✅ Последовательное появление городов на карте  
✅ Карусель с отзывами (автопрокрутка, точки, кнопки, тач-поддержка)  
✅ 3 видеоплеера  
✅ Табы "Что входит в подписку"  
✅ FAQ-аккордеон  
✅ Анимация счётчиков в блоке "Почему нам доверяют"  
✅ Адаптивный дизайн (мобильная версия)
